# Requirements

The calculator must:
- Do addition
- Do subtraction
- Do multiplication
- Do division
- Display the result
- Prompt the user to enter values and operators
- Take inputs from the user
- Display errors (e.g: division by zero, invalid operator, invalid operand)
- Not crash due to user errors

Once all requirements above are reached without any known bugs, the calculator can
be considered complete.

Example valid input:
> Enter a number:
6
> Enter an operator:
+
> Enter another number:
8
> Result of operation: 14

Example invalid input:
> Enter a number:
six
> Invalid number! Please enter a number comprised of digits only (e.g: 53)
6
> Enter and operator:
+
...
